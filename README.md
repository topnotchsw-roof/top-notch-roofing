# Top Notch Southwest Roofing — Vercel Site

## Quick Vercel setup

1. Go to https://vercel.com and sign in with Gmail: djones@topnotchsouthwestroofing.com
2. Click **Add New > Project**
3. Upload/import this project folder, or push it to GitHub and import it.
4. Deploy.
5. In Vercel, go to **Settings > Domains** and add your GoDaddy domain.
6. In GoDaddy DNS, point the domain to Vercel using the records Vercel gives you.
